# F13 — Expanded custom-amp artwork + reroll

Plan a post-1.2.1 enhancement for more varied procedural artwork on custom amps. Keep imported user images out of scope: artwork remains generated by VoLum, portable, and safe in every plugin format.

Design:

- expand the custom-amp procedural style catalog beyond the current six choices;
- add a **Reroll** action that changes the selected style's procedural variation without changing the amp name, captures, cab/channel assignments, or audio;
- store a stable style id plus deterministic seed in `volum-content.json`, with backward-compatible defaults for existing custom amps;
- show the exact same generated identity in the builder, sidebar thumbnail, main hero, MAIN/SUPPORT lanes, presets, and reopened projects;
- keep sidebar thumbnails teal/blue-only and hero-size art within the existing teal/gold design rules;
- avoid unrestricted image import, external URLs, or embedded binary artwork.

Produce a scoped implementation ticket covering UX placement, style/seed schema migration, deterministic rendering, cache invalidation, tests for old/new manifest round-trip and stable rerolls, EN/DE docs, screenshots, and changelog. Implement on a dedicated feature branch off latest `dev`; not in the 1.2.1 hotfix.
