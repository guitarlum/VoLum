08/01/2026 - VoLum 1.2.1 (Reverb): Fixed the discrete reflections - a slapback-like "clatter", most audible on muted notes and at low Mix - in all three reverb modes. Hall and Oktaverb had no input diffusion and read only the far end of each delay line, so the wet signal was silent for the first 52.7 ms (Hall) and then arrived as eight separate impulses; they now share a four-stage allpass diffuser plus a per-channel early field, and the delay lines are injected with alternating sign. Plate was missing the second half of Dattorro's tank, which left both halves the same length: they fired together every 172.2 ms and the output was nearly mono (L/R correlation 0.93). The tank is now complete, with the full seven-tap-per-channel output network. Delay-line lengths, loop gain, mixing matrix and tone curves are unchanged, and the wet level is matched to the old one, so the tails are the same - only the first 200 ms differ.
08/01/2026 - VoLum 1.2.1 (Reverb): PRE-DLY now means what it says. It used to add to a hidden onset floor of 53 ms (Hall) or 172 ms (Plate); the wet signal now starts where the knob sets it. Because that gap is now real and audible, the default pre-delay for new patches moves from 20-30 ms to 10 ms in every mode. Saved presets and settings keep their stored values.
08/01/2026 - VoLum 1.2.1 (Standalone audio): The sample rate display is now the driver's, not the request. An ASIO driver can accept a rate change and stay where it was - typically when its clock comes from its own control panel or an external source - and VoLum used to believe the request: Preferences showed it, settings.ini stored it, and the plugin ran at it while the hardware ran at something else.
08/01/2026 - VoLum 1.2.1 (Standalone audio): VoLum now follows the interface when its sample rate is changed from the vendor's own control panel, instead of going silent until it is restarted. Both routes a driver can use to announce this are handled, and repeated reopen requests are capped so a driver cannot put the app in a loop.
08/01/2026 - VoLum 1.2.1 (Standalone audio): A sample rate in settings.ini that the current device does not offer is corrected to the nearest one it does, and written back, instead of failing to open. Audio failures during startup are now reported once the window exists - previously they were posted to a window that did not exist yet, so the app came up silent with no explanation.
08/01/2026 - VoLum 1.2.1 (Standalone startup/shutdown): Launching while a previous instance is still shutting down now waits for it, and a previous instance that is stuck with no window says so instead of the launch appearing to do nothing. Plugin teardown at quit is now bounded by its own watchdog, so a hang there can no longer leave a windowless VoLum holding the audio device.
08/02/2026 - VoLum 1.2.1 (Standalone audio): Starting with your interface unplugged no longer replaces your audio settings. When no device could be opened, VoLum fell back to a state that describes "the last stream that worked" - which, before any stream has worked, is a set of defaults - and then wrote it to settings.ini. One start without the interface therefore replaced the device, channels, buffer size and sample rate permanently: plugging the interface back in restored the hardware but not the settings, because the file no longer named it. A start that cannot open any device now leaves the file alone.
08/02/2026 - VoLum 1.2.1 (Standalone startup): A machine that cannot provide OpenGL 2.0 is now told so, instead of VoLum disappearing the instant it is started. Windows substitutes a basic OpenGL 1.1 implementation whenever no real one is available - a Remote Desktop session, a virtual machine without 3D acceleration, a graphics driver that failed to load or is missing after an update - and VoLum's drawing library then called into it and crashed, with no window and nothing in any log to explain it. VoLum now checks before it draws and explains what is wrong and what to do about it. Only the standalone app is affected; in a DAW the host has already created the graphics.
