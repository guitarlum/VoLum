VoLum 1.2.0  Art Candidates

Procedural options ported to HTML canvas from the real drawing code in VoLumFractalArt.h / VoLumTriptychMotifs.h, same teal/gold palette. Each row shows the current design (gold dashed) plus new candidates. Judge at this large size; the tiny sidebar thumbnail is derived after you pick. Tell me a letter per item, e.g. "JMP = C".

Gradients / glow are used in some candidates. These port to iPlug2 IGraphics via IPattern linear/radial gradient fills plus layered-alpha strokes (canvas shadowBlur is emulated in C++ with a few concentric translucent passes). Nothing shown here is un-buildable.

Palette: teal rgb(120,210,220), mid rgb(100,180,200), dim rgb(80,150,170), gold rgb(200,165,87).
