# VoLum 1.2.0 — standalone test bug tracker

Persistent log of bugs reported during standalone testing so status survives
session compression. Update the **Status** column every time an item changes.

Status legend: `OPEN` (reported, not fixed) · `FIX-CLAIMED` (code changed, not
yet user-verified) · `VERIFIED` (confirmed fixed, by screenshot/test or user) ·
`WONTFIX`.

## Verification workflow (do this for every UI fix before claiming done)

1. Kill stale instances: `Get-Process VoLum,VoLum_x64 | Stop-Process -Force`
   (the postbuild copies `VoLum.exe` -> `VoLum_x64.exe`; a running `VoLum_x64`
   locks the copy and silently keeps you on an old binary).
2. Build + launch: `pwsh NeuralAmpModeler/scripts/run-app-win.ps1`.
3. Screenshot the live window:
   `pwsh NeuralAmpModeler/scripts/win-screenshot.ps1 -ProcessName VoLum -OutFile C:\tmp\shot.png`.
4. Open the PNG, zoom the region, and sample pixels (System.Drawing `GetPixel`)
   to confirm the actual rendered result — do not assume a code edit took effect.
5. Confirm the edited draw path is the one actually used (watch for overridden
   `DrawWidget`/`Draw` in subclasses — base-class edits can be dead code).
