# VoLum 1.2.0 — User-guide update checklist (BYO + Presets)

Status: **parked until the backend session lands.** Per the VoLum workflow rule
the user guide is only updated once a feature is wired up and user-facing for
real (not while it is a UI shell on a mock). This file is the to-do list for that
later "user manual" session so nothing is forgotten.

Keep `docs/user-guide.en.md` and `docs/user-guide.de.md` **in sync**, and refresh
the stable `docs/user-guide-*.png` screenshots for any view whose visuals change.

## New / changed sections to write

1. **Presets** (new section, after `## Choose An Amp`)
   - Per-amp named snapshots; the preset bar in the top header (`‹ name ›`).
   - `‹` / `›` cycle presets in place (footswitch/MIDI mappable once wired).
   - `(unsaved)` appears when the live rig diverges from the recalled preset.
   - Preset dropdown: `Default (factory settings)` (only when presets exist) →
     presets → `Manage presets…`.
   - Manage presets: Save current as new, Overwrite (with confirm), Rename,
     Delete; double-click a row to recall.
   - New screenshot: `user-guide-presets.png`.

2. **Custom amps (Bring your own)** (new section)
   - The sidebar `CUSTOM` section; `+` to add, pen to edit, bin to delete.
   - The builder: name (required), art picker, `+ Add .nam files`, the speaker +
     channel chips, the coverage grid, rename cabs, validation/Save rules.
   - Explain the filename auto-fill (`PREFIX-CODE-CHANNEL.nam`) and that
     non-matching files import unassigned.
   - New screenshot: `user-guide-custom-amp.png`.

3. **Custom IR cabs (Bring your own IR)** (extend `## Main View` cabinet row)
   - The single cabinet row: `No Cab | <cab1> <cab2> <cab3> | Custom IR`.
   - `Custom IR` dropdown: pick from the IR library / `Manage custom IRs…`;
     selecting a baked cab or No Cab clears the custom IR.
   - Note the distinct copper highlight for an active Custom IR.
   - Refresh `user-guide-main.png` (cabinet row changed).

4. **Imported pedals** (extend `## PRE Section`)
   - The `CUSTOM` group in the PRE capture dropdown; `Manage custom pedals…`
     (import `.nam`, rename, delete).

5. **Dual Amp** (update `## Dual Amp`)
   - Support partner is a factory amp. A custom amp can be the **main** amp with
     full dual support. (No custom support partner in this release.)

## Cross-cutting notes for the writer

- Names must be unique within their own list (presets/IRs/pedals);
  cross-type duplicates are fine.
- Every icon button has a hover tooltip — mention this once in Keyboard/UX.
- Esc closes the active overlay/dropdown; clicking outside also closes it.
- Don't document custom support partner or settings import/export — the former is
  deferred (see spec §2.5), the latter is `backlog/F10-settings-import-export.md`.
