# Analog Delay

Analog delay keeps the Memory Man-inspired staging work: darker BBD-style repeats, compander motion, soft feedback saturation, and a small chorus movement on the wet line.

Visible controls:

- `Time`, `Feedback`, `Mix`.
- `Tone`: wet-repeat brightness tilt.
- `Wear`: increases BBD darkness, chorus depth, and compander softness.
- `Ping-Pong`: stereo cross-feed toggle for alternating repeats.

The default `Wear` value is `0.5`, giving audible analog character without pushing into broken or tape-like modulation.
