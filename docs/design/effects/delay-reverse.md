# Reverse Delay

Reverse delay restores the dev-era reverse core and keeps the staging Tone/Age slot as an additive character control.

Visible controls:

- `Time`, `Feedback`, `Mix`.
- `Tone`: wet reverse-slice brightness tilt.
- `Bloom`: softens the reverse slice envelope.

`Bloom = 0` preserves the old edge-faded reverse behavior. Higher values blend toward a smoother `sin^2` swell for more pad-like reverse tails. `Ping-Pong` is hidden in Reverse because cross-feedback does not map cleanly to reversed slices.
