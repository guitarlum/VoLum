# VoLum Effect Voicing Notes

Shipped PRE/POST character. Update these when the DSP changes.

## Surface

- PRE Compressor: 1176-style FET compressor with a hidden -5 dB output calibration at displayed `Output = 0 dB`.
- Delay: `Digital`, `Analog`, and `Reverse`.
- Reverb: `Hall`, `Plate`, and `Oktaverb`.

Tape delay and TremVerb were tried and dropped. Do not resurrect them without a ticket.
